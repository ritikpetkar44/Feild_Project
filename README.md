# 🌾 Farmer Financial Literacy Portal – Field Visit Documentation

## 📌 Project Overview
This repository contains the field visit documentation for the **Farmer Financial Literacy Portal** project, carried out as part of the **Field Project** by Second Year B.Tech students of **S. B. Jain Institute of Technology, Management & Research**.

The objective of this project is to understand the financial awareness, banking practices, and digital literacy of farmers and to develop a portal that can help improve their financial knowledge.

---

## 📍 Field Visit Details

- **Village:** Dahegaon
- **Activity:** Farmer Interaction & Survey
- **Project Type:** Field Project
- **Academic Year:** Second Year B.Tech

During the visit, our team:
- Interacted with local farmers.
- Collected preliminary information.
- Documented observations.
- Captured geo-tagged photographs for project records.

- Design a user-friendly Farmer Financial Literacy Portal.
